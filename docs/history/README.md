# Historico da Documentacao

Esta pasta guarda documentacao preservada como evidencia historica, referencia de auditorias antigas ou consolidacoes anteriores.

## Regra de uso

- estes arquivos nao sao a fonte operacional principal da plataforma Next na raiz
- quando houver conflito entre um documento desta pasta e um documento ativo na raiz de `docs/`, vale o documento ativo
- a referencia canonica da migracao e consolidacao atual continua em `NEXT_PLATFORM_CONSOLIDATION.md`, `NEXTJS_MIGRATION.md` e `PRODUCTION_READINESS_AUDIT_PLAN.md`

## Subpastas atuais

- `admin/`: auditorias, validacoes e consolidacoes antigas do painel admin
- `consolidated/`: dossies grandes de consolidacao que preservam contexto historico, mas nao devem guiar a operacao atual sem revalidacao
